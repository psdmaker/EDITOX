GitHub-এ আপলোডের নিয়ম:
1. এই ZIP আনজিপ করুন।
2. GitHub-এ New repository বানান (নাম: editox), তারপর "uploading an existing file" লিংকে চাপুন।
3. আনজিপ করা ফোল্ডারের ভেতরের সব ফাইল ও .github ফোল্ডার একসঙ্গে টেনে ছেড়ে দিন, তারপর Commit changes চাপুন।
4. Actions ট্যাবে যান, বিল্ড সবুজ টিক পেলে সেটাতে ঢুকে নিচে Artifacts থেকে EDITOX ডাউনলোড করুন।
5. ডাউনলোড করা ZIP আনজিপ করলে EDITOX.exe পাবেন।
